# Glosario Pedagógico - Del Ecosistema C# / Java a TypeScript y Next.js

Este glosario es una "Piedra de Rosetta" técnica diseñada para que un desarrollador con experiencia en **C# / ASP.NET Core** o **Java / Spring** comprenda de inmediato las herramientas, conceptos y convenciones del ecosistema moderno de JavaScript/TypeScript presentes en BX Boutique.

---

| Concepto en este Proyecto              | Equivalente en C# / Java                                | Equivalente en Java / Spring                                    | Explicación en 2-3 líneas simples                                                                                                                                                                                                       |
| -------------------------------------- | ------------------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Zod**                                | `FluentValidation` / `DataAnnotations`                  | `Jakarta Bean Validation` (Hibernate Validator)                 | Validador de esquemas e invariantes en tiempo de ejecución (runtime). Se usa para sanitizar entradas de formularios, llamadas a API y variables de entorno, infiriendo el tipo TypeScript correspondiente.                              |
| **Drizzle ORM**                        | `Entity Framework Core` (Fluent API) / `Dapper`         | `Hibernate` / `JDBI`                                            | ORM de bajo nivel sin "magia" ni proxies. Escribís esquemas fuertemente tipados en TypeScript que compilan 1 a 1 a SQL estándar ultra veloz, sin tracking en memoria oculto.                                                            |
| **Tailwind CSS**                       | Clases utilitarias atómicas / DSL de estilos compilado  | Clases utilitarias atómicas                                     | Compilador que analiza los archivos de la app y genera en tiempo de build un CSS mínimo con únicamente las clases utilitarias utilizadas (tree-shaking de estilos sin archivos `.css` manuales sueltos).                                |
| **`clsx` + `tailwind-merge` (`cn()`)** | `string.Join()` / `StringBuilder` inteligente           | Utilidad de composición de cadenas con resolución de conflictos | Función utilitaria que permite concatenar clases condicionales de Tailwind y resuelve colisiones de especificidad (si pasás `p-4` y condicionalmente `p-2`, gana `p-2` sin errores visuales).                                           |
| **Radix UI Primitives**                | Controles desacoplados en WPF / XAML                    | Controles UI desacoplados en JavaFX                             | Componentes sin estilos visuales (headless) que resuelven la accesibilidad compleja (atrapar el foco del teclado, eventos `Escape`, atributos `aria-*` para lectores de pantalla) mientras vos aplicás el 100% del diseño con Tailwind. |
| **`lucide-react`**                     | Paquetes NuGet de íconos (FontAwesome / Material Icons) | Librería de íconos SVG vectoriales                              | Conjunto de íconos SVG limpios, modernos y optimizados para e-commerce (bolsa de compra, lupa, cerrar, tilde). Incluye solo los íconos usados en el bundle final.                                                                       |
| **Server Components (RSC)**            | `ASP.NET Core Razor Pages` / `Blazor Server`            | `Thymeleaf` / `Spring MVC SSR`                                  | Componentes de React que se ejecutan **únicamente en el servidor**. Tienen acceso directo a la base de datos y secretos, enviando HTML estático ya procesado al navegador, con cero kilobytes de JavaScript agregado al cliente.        |
| **Client Components (`'use client'`)** | `Blazor WebAssembly` / Controles interactivos de UI     | Componentes JS en frontend / JSP interactivo                    | Componentes que se descargan y ejecutan en el navegador para manejar interactividad en tiempo real (clicks, animaciones, `useState`, apertura de menús o modales).                                                                      |
| **Server Actions**                     | Métodos `[HttpPost]` en Controllers con RPC automático  | Métodos `@PostMapping` en `@Controller`                         | Funciones asíncronas escritas en el servidor que pueden invocarse directamente desde componentes cliente de React como si fueran llamadas a métodos locales. Next.js maneja la serialización y el transporte HTTP.                      |
| **Route Handlers (`route.ts`)**        | `ASP.NET Core Web API` (`[ApiController]`)              | `Spring @RestController`                                        | Endpoints HTTP tradicionales para responder JSON puro o recibir webhooks de terceros (como Mercado Pago). Se usan cuando no se está renderizando una interfaz visual.                                                                   |
| **`next/font`**                        | Empaquetado de fuentes locales en el assembly           | Fuentes embebidas en el JAR                                     | Descarga y hospeda automáticamente las fuentes de Google Fonts en el servidor del proyecto, eliminando llamadas externas al cargar la web y evitando saltos visuales en pantalla (Layout Shift).                                        |
| **Vitest**                             | `xUnit` / `NUnit`                                       | `JUnit 5`                                                       | Framework moderno y veloz de pruebas unitarias y de integración para TypeScript, con soporte nativo de ESM, mocks y aserciones.                                                                                                         |
| **Playwright**                         | `Playwright .NET` / `Selenium WebDriver`                | `Playwright Java` / `Selenium`                                  | Herramienta de automatización de navegadores que ejecuta pruebas de extremo a extremo (E2E) simulando a un usuario real comprando y pagando en Chrome/Safari/Firefox.                                                                   |
| **pnpm**                               | Administrador de paquetes NuGet                         | Maven / Gradle                                                  | Gestor de paquetes para Node.js basado en enlaces rígidos (hard links) y almacenamiento global deduplicado. Ahorra espacio en disco y acelera las instalaciones.                                                                        |
| **Supabase Auth**                      | `ASP.NET Core Identity` con autenticación TOTP          | `Spring Security` con módulos OAuth2 / MFA                      | Servicio gestionado de autenticación de usuarios que maneja hash de contraseñas (bcrypt/argon2), tokens JWT, cookies de sesión seguras y segundo factor de autenticación (MFA).                                                         |
| **Resend + React Email**               | `SendGrid` con plantillas Razor compiladas              | `Spring Mail` con plantillas Thymeleaf                          | Servicio de entrega de correos transaccionales que permite diseñar los emails como si fueran componentes de React fuertemente tipados.                                                                                                  |
| **Result Pattern (`Result<T, E>`)**    | `OneOf<T, Error>` / `Result<T, Exception>`              | `Either<L, R>` (librería Vavr)                                  | Patrón de diseño donde las funciones no lanzan excepciones para control de flujo, sino que devuelven un objeto `{ success: true, data }` o `{ success: false, error }`, forzando a manejar los errores explícitamente.                  |
| **Validación de Entorno (`env`)**      | `IOptions<T>` con `ValidateOnStart()`                   | `@ConfigurationProperties` con `@Validated`                     | Valida todas las variables del `.env` con Zod durante el arranque del proceso. Si falta una variable requerida, la aplicación aborta inmediatamente con un mensaje de error claro en lugar de fallar en producción.                     |
| **`server-only`**                      | Modificadores `internal` y directivas `#if SERVER`      | Restricción de visibilidad a nivel de ClassLoader               | Lanza un error fatal en tiempo de compilación si algún archivo que contiene código de servidor, consultas a DB o secretos es importado por error desde un componente del cliente.                                                       |
| **Connection Pooler (Supavisor)**      | `PgBouncer` / Pool de conexiones de ADO.NET             | `HikariCP` en modo proxy                                        | Servidor intermedio que administra y reutiliza un número fijo de conexiones físicas a PostgreSQL. Esencial para entornos serverless (como Vercel) para no saturar los sockets de la base de datos.                                      |
| **Middleware de Next.js**              | `ASP.NET Core HTTP Middleware` (`app.Use(...)`)         | `Servlet Filters` de Java EE / Spring Filter                    | Intercepta cada petición HTTP antes de que llegue a las páginas, utilizado aquí para verificar sesiones de administración y redirigir al login si falta autenticación o MFA.                                                            |
